## 五、四项必须披露的机制发现

1. **F1 档对该实现不敏感（设计缺陷，如实标注）**：结构侧只用 `subject`，种子置换不改结构排序；A 冻结件在群内 PR 全并列，置换种子只改群内序号、命中集合不变 → F1 与 A0 数值完全一致。**F1 不构成独立 OOD 证据**，M2 实际只有 A0/F1null/F2 三档有效。
2. **A/B 都在"群内均匀分布"上打分**：同群即全连通时，PR 值在群内并列，名次由「群内成员顺序」决定。A 侧该顺序由实体表序产生，命中率 0.067 接近随机；B 侧 0.444 反映的是"种子落在哪个群"，而非"群内谁更相关"。这解释了为何 B 的 `recall@5` 高而 `pr@5` 仍低（0.107）。
3. **F2 使 B 崩至 0.03**：破坏实体↔向量对应后 B 优势消失，符合"B 的优势依赖真实 embedding 结构"的预期，反向支持 B 结论非伪。
4. **degree 与 frequency 在本图完全等价**：30 条查询下两者 PR@5 均为 0.080，M1 的 `degree > frequency` 一段在数学上不可能成立 → 该判据在本图上先验不可满足（这是设计层的可判性问题，非假设问题）。
