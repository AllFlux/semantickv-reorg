# DS-20261019-021-WB1 评审归档（WB1 intake）

# 理论背景（Why）

你需要的文件（`router_weights.pt`、`load_test.py` 等）目前只存在于 WB2 的
沙盒里。我们决定用你之前建好的 `AllFlux/semantickv-reorg` 仓库作为数据总线。
你需要在 Kaggle 的 Notebook 启动时，自动从远端把 `src/shared/` 拉下来，
而不是等本地同步。

# 具体步骤（What）

1. **编写拉取脚本 (`auto_pull_shared.py`)**：接收环境变量 `GITHUB_PAT`；
   运行 `git clone https://{GITHUB_PAT}@github.com/AllFlux/semantickv-reorg.git temp_repo`；
   将 `temp_repo/src/shared/` 复制到当前工作目录的 `src/shared/`；
   计算并打印所有拉取文件的 SHA256 哈希值，与远端 commit 日志比对。
2. **在 Notebook 中挂载**：在 `run_on_kaggle.ipynb` 的环境准备阶段加入执行
   `auto_pull_shared.py` 的 Cell；执行后确认 `router_weights.pt` 在本地可见。

# 验收标准（How）

- **拉取成功**：终端输出 `Pull Success: router_weights.pt (SHA256: xxx)`。
- **加载成功**：脚本跑完后，模拟空壳能通过 `torch.load()` 直接读取拉取下来的真实权重。
- **数据存证**：`results/logistics_pull_test.json`（记录耗时与文件哈希）。
