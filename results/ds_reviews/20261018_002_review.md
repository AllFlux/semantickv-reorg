# 理论背景（Why）

从架构构思、CPU 纯算法模拟到真实小模型（0.5B）隐空间探查的全过程整理。核心理论启示：(1) LLM 隐空间天然低秩→各向异性→余弦系统性失效；(2) 纯增量更新必有数学滞后极限 (1-α)·Δw→须 Max Stale 硬约束兜底；(3) 均值是破坏局部细节的毒药→须 Top-K/加权+Sink 保护；(4) 层间分工须从硬编码走向可学习 Selector。

# 具体步骤（What）

度量与分组：先白化再聚类（Mean-Centering/ZCA），备选 L1/秩度量，不要迷信 L2。压缩策略：Top-K 代表保留（K=2 或 4）、分层（中间层 6-10）、Anchor 保护（前 4 token + 最近 N token 踢出压缩池）、禁全层 flat-mean。调度：Pareto 组合 K=3+α=0.8、分阶段重组（边界全量/Decode 仅 EMA）、不阻塞 GPU。模型与评估：换 7B/Llama-8B 复核、真实显存降 30%+、不用合成数据替代真实隐空间。

# 验收标准（How）

- 第一行动序列：改 Grouper 加 Mean-Centering → 改 KV 压缩为 Top-K+Sink → 0.5B 切片看 argmax 能否 2.32%→80%+（H-DS2）→ 上 Kaggle 7B 跑「基线→中间层+Top-K→加调度」三阶段。
- 显存须实降 30%+（H-DS5）。
- Pareto 组合 K=3+α=0.8 为最优（H-DS3，已证伪见上）。
