# DS-20261019-026-WB1 评审归档（WB1 intake）

# 理论背景（Why）

既然 WB2 的旧权重被证明不可直接用于 KV 路由，我们就兵分两路。让 WB2 去炼新剑，
而 WB1 直接用「GSC 离线质心」或「随机初始化的空壳」作为路由方案。我们需要先确认：
7B 模型在 8K 长度下，哪怕用不是最优的群划分，混合保护机制（保底 Sink + 滑窗）
是否能先稳住 45% 以上的 Argmax 底线？

# 具体步骤（What）

1. **Kaggle 环境启动**：确认已经拉取了最新代码。
2. **突击基线测试**：
   - 跑无压缩基线（目标 ≥2/3）。
   - 跑混合保护，但路由层用一个简单的策略（比如直接选前 K 个群，或者纯粹基于
     Query 与 Key 的简单点积）。
3. **对比 RoPE 连续性影响**：记录在拼接重组 KV 时，是否出现了明显的精度崩塌
   （如果是，说明问题出在相对位置编码上）。

# 验收标准（How）

- **前置门禁**：7B 无压缩基线 ≥ 2/3。
- **底线测试**：在任何可用路由策略下，混合保护的 Argmax 若 > 45%，则维持方案；
  若 < 45%，标记 `ROPE_FRACTURE`。
- **数据存证**：`kaggle_7b_fixed_route.json`。
